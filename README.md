# I'll Be Bag — playable prototype build

A cinematic 3D physics game about a plastic bag. You never steer; you read the wind and change
the bag's SHAPE. First district: Allenby Street, Tel Aviv.

**Play:** open this repository's GitHub Pages URL.

Controls — keyboard: ↑ open (parachute) · ↓ crumple (stone) · → flat (wing) · Space anchor.
Touch: plant a thumb in the lower third and slide toward a corner; lift to release. Every touch
is also an anchor commit.

This repository holds ONLY a compiled web build, published so the prototype has a stable link.
The game's source lives in a private repository.
